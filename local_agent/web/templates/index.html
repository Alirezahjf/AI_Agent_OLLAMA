تنظیمات

ارائه‌دهنده را روی «سازگار با OpenAI» و آدرس را روی https://api.avalai.ir/v1 تنظیم می‌کند؛ فقط کلید API را وارد کنید.

کلید فقط روی همین دستگاه ذخیره می‌شود و هرگز به جایی ارسال نمی‌شود. «تشخیص خودکار» کلید و آدرس را می‌خواند و ارائه‌دهنده (مثلاً AvalAI یا GapGPT) و لیست واقعی مدل‌ها را بازمی‌گرداند.

{{ billing && billing.error ? billing.error : "درگاه مالی در دسترس نیست." }}

موجودی، بسته‌ها، مصرف ۲۴ ساعت و تراکنش‌های اخیر بر اساس User API رسمی ارائه‌دهنده (برای AvalAI: api.avalai.ir/user/v1) خوانده می‌شود.

همهٔ فایل‌ها به‌طور پیش‌فرض داخل همین پوشه ساخته می‌شوند؛ اگر وجود نداشته باشد، ساخته می‌شود.

اتصال‌ها و یکپارچه‌سازی‌ها

api_id و api_hash را از my.telegram.org بگیرید. بعد از ذخیره، دکمهٔ «اتصال» را بزنید؛ کد SMS و در صورت نیاز رمز 2FA پرسیده می‌شود و سشن ذخیره می‌شود تا بعد از ری‌استارت نیازی به لاگین دوباره نباشد.

            Projects v2 — بررسی جمعی، جزئی و ساخت
            

              
              
              
            

            

              
            

            

              
              
            

            

            
برای ساخت Project سازمانی، ابتدا Projectهای همان سازمان را دریافت کنید تا شناسهٔ GraphQL مالک به‌صورت امن مشخص شود.

          


          

            Actions Secrets و Variables محافظت‌شده
            
مقدار Secret از مسیر مستقیم UI به backend می‌رود، با کلید عمومی همان scope رمزگذاری و فوراً از فرم پاک می‌شود؛ هرگز وارد گفتگو، ابزار مدل، URL یا تنظیمات ذخیره‌شده نمی‌شود.

            

              
              
            

            
            

              
              
            

            
            
            

              
              
            

            

              
              
            

          


          

            Webhook محافظت‌شده
            
Secret امضای Webhook فقط از مسیر مستقیم UI فرستاده و بلافاصله پاک می‌شود. این برنامه Webhook را در GitHub مدیریت می‌کند؛ دریافت رویداد عمومی به سرور HTTPS جداگانه نیاز دارد.

            
            

              
              
            

            

              
              
              
            

            
            

              
              
            

          


          

            کنسول پیشرفتهٔ عملیات مجاز GitHub
            
فقط operationهای ثابت backend اجرا می‌شوند؛ URL، روش HTTP و GraphQL دلخواه پذیرفته نیست. عملیات نوشتنی دوباره تأیید می‌گیرند و Secretهای دارای مقدار عمداً در این فهرست نیستند.

            

              
              
            

            

              
              
            

            
            

              
              
            

            

          

        


        

          
          

            
            
          

          

            
            
          

          
          

            
            
          

          
          

            روش ترجیحی: در Google Cloud Console یک OAuth Client (Desktop app) بسازید و
            credentials.json را در پوشهٔ داده بگذارید. بدون OAuth می‌توانید «App Password» گوگل را
            (با فعال‌کردن تأیید دومرحله‌ای) در اینجا وارد کنید.
          

          

            
            
            
          

        

        

          

            
            
          

          

            وقتی فعال باشد، ایجنت می‌تواند هر پوشه‌ای از سیستم را بخواند/بنویسد و شل را در هر
            جایی اجرا کند. فایل‌های حساس (.ssh، .env، credentials و...) در هر حالتی مسدود می‌مانند
            و کارهای مخرب همچنان تأیید می‌گیرند.
          

          

            ⚠️ سطح دسترسی فعلی برنامه:  — برای مدیریت کامل
            سیستم، برنامه را «به‌عنوان administrator» (ویندوز) یا با sudo (لینوکس) اجرا کنید.
            
          

          

            
⚠️ مطمئن هستید؟ دسترسی کامل سیستم به ایجنت می‌دهد همهٔ فایل‌های شما را مدیریت کند.

            

              
              
            

          

        

        

          
          
        

        

          
          
        

        

          
          
        

        

          
          

            همهٔ داده‌های دستیار — تنظیمات، تاریخچهٔ گفتگو، حافظه، لاگ‌ها، اسکرین‌شات‌ها و توکن‌ها —
            برای همیشه حذف می‌شود و ثبت «اجرای خودکار» لغو می‌گردد.
            کتابخانه‌های نصب‌شده و محیط مجازی حذف نمی‌شوند تا نصب دوباره نیاز به اینترنت نداشته باشد.
            این عمل قابل بازگشت نیست؛ برنامه بعد از پاک‌سازی بسته می‌شود.
          

          

            
          

          

            
⚠️ مطمئن هستید؟ هیچ‌چیز از دستیار روی سیستم باقی نمی‌ماند.
