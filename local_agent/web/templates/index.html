تنظیمات

ارائه‌دهنده را روی «سازگار با OpenAI» و آدرس را روی https://api.avalai.ir/v1 تنظیم می‌کند؛ فقط کلید API را وارد کنید.

کلید فقط روی همین دستگاه ذخیره می‌شود و هرگز به جایی ارسال نمی‌شود. «تشخیص خودکار» کلید و آدرس را می‌خواند و ارائه‌دهنده (مثلاً AvalAI یا GapGPT) و لیست واقعی مدل‌ها را بازمی‌گرداند.

{{ billing && billing.error ? billing.error : "درگاه مالی در دسترس نیست." }}

موجودی، بسته‌ها، مصرف ۲۴ ساعت و تراکنش‌های اخیر بر اساس User API رسمی ارائه‌دهنده (برای AvalAI: api.avalai.ir/user/v1) خوانده می‌شود.

همهٔ داده‌های دستیار — تنظیمات، تاریخچهٔ گفتگو، حافظه، لاگ‌ها، اسکرین‌شات‌ها و توکن‌ها — برای همیشه حذف می‌شود و ثبت «اجرای خودکار» لغو می‌گردد. کتابخانه‌های نصب‌شده و محیط مجازی حذف نمی‌شوند تا نصب دوباره نیاز به اینترنت نداشته باشد. این عمل قابل بازگشت نیست؛ برنامه بعد از پاک‌سازی بسته می‌شود.

⚠️ مطمئن هستید؟ هیچ‌چیز از دستیار روی سیستم باقی نمی‌ماند.
